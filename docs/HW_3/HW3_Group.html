Task 1: Conceptual Questions

  1. If your working directory is myfolder/homework/, what relative path would you specify to get the file located at myfolder/MyData.csv?

    The relative path would be "../MyData.csv". The ../ moves from the working directory myfolder/homework/ up one level to the directory myfolder/.

  2. What are the major benefits of using R projects?

    • Allows for the creation of a file hierarchy when working on one project that contains multiple files
    • Associated with a directory, which becomes the working directory for the project
    • Working directory can be used for coding using relative paths
    • When you render a .qmd file, the working directory for that rendering corresponds to the folder in which the .qmd file is located
    • Connects to Git and Github to allow for version control and collaboration, which can be managed directly in RStudio
    • Functions as a storage space for all information associated with a given project

  3. What is Git and what is GitHub?

    Git is version control software, which is useful for tracking changes to files and collaborating with others. GitHub is an online hosting service for Git-based projects, allowing your repository to be stored on the web and accessed remotely.

  4. What are the two main differences between a tibble and a data.frame?

    A tibble is a type of data.frame that is specific to the tidyverse package. The two main differences are:

    1. The default print() method for a tibble has fancier printing: it shows the number of observations and columns and displays only the first few rows/columns.
    2. tibbles do not coerce down to a vector when you subset to only one column using [.

Task 4: Writing a Function

Write getIQR function.

getIQR <- function(x){
  if(!is.vector(x)){
    stop("Not a vector.")
  }
  return(as.vector(quantile(x)[4] - quantile(x)[2]))
}

Write getCoefVar function.

getCoefVar <- function(x){
  if(!is.vector(x)){
    stop("Not a vector.")
  }
  return(sd(x) / abs(mean(x)))
}

Write getSummaries function.

getSummaries <- function(x){
  if(!is.vector(x)){
    stop("Not a vector.")
  }
  return(c(IQR = getIQR(x), CoefVar = getCoefVar(x)))
}
