  1. “Long format” refers to the more common data layout, where each row corresponds to a single observation or data point, often (but not always) separated by time. “Wide format” data features multiple grouped observations in a single row, united by a common variable (city, week, team, etc.). Data in this format is typically more difficult to analyze, and usually requires transformation into long format data, which is preferred for statistical analysis.
